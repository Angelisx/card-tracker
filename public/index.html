API token

Use this token from other sites, scripts, or an AI dashboard to read your wallet data. Set/rotate it in Netlify env vars (API_TOKEN) — it is never shown here for security.

REST export

JSON: GET /api/export?token=YOUR_API_TOKEN

CSV: GET /api/export?format=csv&token=YOUR_API_TOKEN

MCP endpoint

Point an MCP-compatible client at:

/mcp

Send Authorization: Bearer YOUR_API_TOKEN. Tools exposed: list_my_cards, list_all_cards, best_card_for_category, best_card_by_all_categories, add_card_to_wallet, remove_card_from_wallet.

Outgoing webhook

Whenever your wallet changes, POST the updated wallet to this URL (e.g. Zapier, Make, n8n, your own dashboard).
